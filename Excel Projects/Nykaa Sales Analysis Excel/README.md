# Nykaa Sales Analysis - Excel

## Project Overview

This project analyzes Nykaa sales data using Microsoft Excel to evaluate sales performance, customer trends, product insights, and business KPIs through dashboards, pivot tables, and visualization techniques.

The project focuses on generating actionable retail and sales insights using Excel analytics tools.

# E-commerce Customer Churn Analysis - SQL

## Project Overview

This project analyzes e-commerce customer churn data using SQL to identify customer behavior patterns, retention trends, purchasing activity, and business insights through structured query analysis.

The analysis helps businesses understand customer attrition and supports data-driven retention strategies.

---

## Business Problem

E-commerce companies need to identify customer churn patterns to improve customer retention, reduce attrition, and optimize business growth strategies.

This project focuses on analyzing customer transactions and behavioral data to uncover churn-related insights using SQL.
